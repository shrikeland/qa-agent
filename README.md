# qa-agent

Каркас и Obsidian-волт ежедневного QA-агента (Claude Code Routine `qa-testing-agent`).

## Структура
- `.claude/skills/qa-test-planner/` — вендоренный скилл генерации тест-кейсов/чек-листов (облачная сессия рутины подхватывает его автоматически).
- `notes/` — сгенерированные заметки по задачам (`MIA-XX.md`); `notes/_daily/` — дневные индексы. Это волт для Obsidian (Obsidian Git тянет на телефон).
- `state.json` — состояние дедупа (ключ задачи → `updatedAt` + `hash` контента). **Не редактировать вручную.**

## Как работает
Раз в день рутина: тянет задачи из Linear (статусы `Ready for Test` / `Testing`), поднимает код фичи из GitLab (по ветке задачи), читает компоненты для UI-грундинга, генерит QA-доку через `qa-test-planner`, коммитит заметки сюда (в `main`) и шлёт сводку в Telegram. Полный промпт пайплайна — в настройках рутины (Instructions), копия в `ROUTINE_PROMPT.md`.

## Правки заметок
Ручные правки в `notes/*.md` сохраняются: агент перегенерирует заметку только если задача в Linear изменилась (по `hash` контента). Неизменённые задачи не трогает.
