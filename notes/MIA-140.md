## Реализация (кратко)

- `scripts/build-og-image.py` — берёт контуры логотипа прямо из `frontend/components/mia360-logo.vue` (regex по `:fill="colors.*" d="..."`, вариант `wordmark`, тёмные цвета), шрифты — `eb-garamond-v32-*` и `inter-v20-*` из `frontend/public/fonts`, иллюстрацию — `frontend/public/images/mia.png`. Константы в скрипте: `HEADING = ('Подготовка', 'по математике')`, `SUBTITLE = ('для 5-9 класса', 'с AI-ассистентом Мией')` — совпадает с тем, что подтвердил предыдущий QA-прогон на картинке.
- `mia360-logo.vue` — один SVG-компонент с `tone` (`dark`/`light`) и `variant` (`full`/`wordmark`/`mark`); используется и на лендинге, и в админке через `mia360-admin-logo.vue` — общий источник для сайта, админки и OG-скрипта.
- Письма: бренд «Mia360» → «Мия360» в `partials/header.mjml`, `partials/footer.mjml`, `partials/head.mjml` и телах шаблонов; футер (`partials/footer.mjml`, подключается во все письма) теперь — «Мия360 — ИИ-репетитор по математике для 5-9 классов.» — подтверждено чтением файла.

**Перепроверено по коду (origin/master, `git show`/`git grep`):**
- Строка в `api/src/services/email/templates/remindLater.mjml` (строка 26) буквально: `Мия - это AI-репетитор по математике для 5-8 класса. Она помогает ребёнку найти пробелы...` — баг из QA-отчёта подтверждён, ещё не исправлен.
- В папке `api/src/services/email/templates/` 14 шаблонов писем (+ 3 партиала `head`/`header`/`footer`). Бренд «Мия360» уже везде корректен (проверено `git grep` по всем `.mjml`, латиницы «Mia360» не осталось). Класс/грейд «5-8 класса» вместо «5-9» остался в **двух** шаблонах, а не в одном:
  - `remindLater.mjml` — известный из QA-отчёта FAIL;
  - `welcome.mjml` (строка 9: «Я Мия — AI-помощник по математике для 5-8 класса.») — **не упомянут в QA-отчёте, похоже, пропущен при предыдущей проверке**, тоже требует фикса.

## Чек-лист

1. **[Приоритет] `remindLater.mjml` — известный FAIL, перепроверить после фикса.** Запросить письмо «напомнить позже» (форма подписки на сайте с «напомнить позже» / соответствующий сервис) — в теле должно быть «Мия — это AI-репетитор по математике **для 5-9 класса**» (не 5-8), бренд «Мия360».
2. **Заодно проверить `welcome.mjml`** (письмо при регистрации/выдаче ссылки ребёнку) — та же фраза «AI-помощник по математике для 5-9 класса» (сейчас в коде «5-8», отдельно от известного бага в remindLater — стоит завести отдельно, если разработчик не в курсе).
3. Быстрый обход остальных писем (OTP-код, ссылка для входа, приглашение, окончание/скорое окончание триала, отмена подписки, первое выполненное задание, родительские отчёты) — беглым глазом: логотипа как картинки нет (ожидаемо, это текстовый бренд), везде «Мия360» без латиницы, в футере «...для 5-9 классов».
4. OG-превью на проде/стенде: вставить `https://mia360.ru` (или тестовый домен) в Telegram/ВК — новый знак Мия360, чёрная иллюстрация, «Подготовка по математике» / «для 5-9 класса» (кэш превью живучий — добавить `?v=2` при необходимости). Ранее уже пройдено на test-1 — цель повторной проверки — только убедиться, что не отъехало вместе с фиксом писем.
5. Админка: логотип в сайдбаре — новый знак, текст «Мия360» без «Mia360». (Ранее пройдено на test-1 — не приоритет, но не помешает свериться, что фикс писем ничего не задел.)
