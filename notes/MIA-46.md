## Контекст

Ученик вводит на доске тренажёра/диагностики формулы (дроби, степени, корни) через математическое поле MathLive вместо плоского текста — инструмент «T» заменён на математический ввод. Фича едет тёмным флагом `NUXT_PUBLIC_WHITEBOARD_MATH_INPUT_ENABLED` (по умолчанию `false`; при выключенном флаге доска работает как раньше).

Скоуп по задаче: ввод формул в поле MathLive → рендер на доске → ре-эдит по двойному клику; экспорт (SVG + WebP) и подмешивание в распознавание/оценку как LaTeX; грейд-зависимая клавиатура (7 и 8 класс), запятая как десятичный разделитель.

**Из комментария автора (важно для стенда):** флаг сегодня включён в `true` и на тесте, и на проде (CI-переменные `TEST_`/`PROD_WHITEBOARD_MATH_INPUT_ENABLED`) — фича live, проверять есть где. Также сегодня заведена цель `whiteboard_math_input` в Яндекс.Метрике (её не было, хотя событие уже уходило) — статистика по ней пойдёт только с сегодняшнего дня, прошлые данные не восстановить.

Тулбар обёрнут в `.wb-toolbar__scroll` — на узкой доске ряд инструментов скроллится по горизонтали, при этом сам `.wb-toolbar` держит `overflow: visible`, чтобы попапы (очистка, меню фото) не обрезались.

- **`frontend/composables/use-whiteboard-export.ts`** — `buildSvg` подмешивает формулы как `<image>` с `data:image/svg+xml` (тот же рендер, что на доске).

**Находки по коду (важно для тест-кейсов):**

1. **`whiteboard-math-field.vue:43`** — `const DEBUG_KEEP_KEYBOARD_OPEN = true;` с комментарием тут же «Keep false in normal use - blur closes/commits», но значение оставлено `true`. Из-за этого сейчас **`onBlur` не коммитит поле, а `focusout` не скрывает клавиатуру** — оба обработчика реально навешаны только под `if (!DEBUG_KEEP_KEYBOARD_OPEN)`. Похоже на забытый debug-переключатель, который поехал в прод/тест. Нужно перепроверить вживую — вероятно, клик мимо поля (не по «Готово»/Enter/Escape/ручке клавиатуры) формулу не коммитит и не закрывает клавиатуру.
2. Цвета брендированы хардкодом (`#034f46` в `whiteboard-math-field.vue` и `use-math-keyboard.ts`) вместо SCSS-токена `$color-fathom: #034f46` из `_variables.scss` — не баг для тестирования, но расхождение с `docs/code-style.md` (все цвета — через `$variables.scss`).
3. Грейд для клавиатуры берётся из `useUserStore().user?.grade ?? 7` — если у пользователя `grade` не задан, тихо используется 7 класс (без «Неравенств»).

## Тест-кейсы

### Флаг выключен (baseline, регресс)
1. **TC1.** При `NUXT_PUBLIC_WHITEBOARD_MATH_INPUT_ENABLED=false` на доске тренажёра: тултип инструмента «T» — «Добавить текст», на мобильном вьюпорте кнопка «T» не отображается вовсе (как раньше). Клик «T» → открывается обычный текстовый узел (legacy `TextNode`), не MathLive.

### Открытие математического поля
2. **TC2.** Флаг включён, десктоп. Клик «T» → курсор в режиме ввода → клик по доске → появляется поле MathLive (рамка/каретка в цвете `#034f46`), поле сразу в фокусе, снизу — виртуальная клавиатура MathLive (тема «Основные»: цифры, `+ − · /`, скобки, `\frac`, степень, `x` с вариантами `y a b c n`, запятая, стрелки навигации, `⌫`, «↵», «Готово»). Клавиатура открывается даже на десктопе (не только тач) — это осознанное отклонение от дефолтной политики MathLive.
3. **TC3.** То же на мобильном/планшетном вьюпорте — поле и клавиатура открываются по тапу на «T» → тап по доске.
4. **TC4.** Ученик 7 класса (проверить на тестовом юзере с `grade=7` или без grade) — доступна только клавиатура «Основные», вкладки «Неравенства» нет.
5. **TC5.** Ученик 8 класса — доступны обе клавиатуры/вкладки: «Основные» и «Неравенства» (`< > ≤ ≥ ≠`, `±`, `∈`, `∞`, `[ ]`, `√`, индекс `x_□`, скобка-система `{`, `;`, стрелки).

### Ввод и структуры
6. **TC6.** Ввод простого выражения через клавиатуру MathLive (цифры/операции) — символы появляются в поле корректно, каретка двигается стрелками навигации на клавиатуре.
7. **TC7.** Кнопка `\frac{□}{□}` — вставляет дробь с двумя плейсхолдерами, табуляция/клик между числителем и знаменателем работают.
8. **TC8.** Кнопка `x^□` (степень) — вставляет показатель степени с плейсхолдером.
9. **TC9.** (8 кл.) Кнопка `√` — вставляет корень с плейсхолдером; кнопка `x_□` — вставляет индекс; кнопка системы (`\begin{cases}`) — вставляет фигурную скобку с двумя строками-плейсхолдерами.
10. **TC10.** Запятая на клавиатуре вставляет `,` как десятичный разделитель (напр. «3,5»), а не точку.
11. **TC11.** Физическая клавиатура: ввод латинских букв/цифр/операторов с клавиатуры работает наравне с виртуальной (MathLive принимает keydown).

### Коммит / отмена / закрытие
12. **TC12.** Enter (без Shift) в поле → формула коммитится, рендерится на доске (SVG-картинка через MathJax), поле и клавиатура закрываются, инструмент «T» разоружается (повторный клик по доске больше не открывает новое поле, пока снова не нажать «T»).
13. **TC13.** Клик по «Готово» на клавиатуре MathLive — то же самое: коммит и закрытие.
14. **TC14.** Escape — отмена: поле закрывается, формула не создаётся (для нового ввода) / не изменяется (для ре-эдита, старое значение остаётся).
15. **TC15.** Пустое поле + Enter/«Готово» → трактуется как отмена (`handleMathCommit` с пустым latex вызывает cancel) — ничего не создаётся на доске.
16. **TC16. (регрессия на находку #1)** Клик мимо поля/по доске (blur), не через «Готово»/Enter/Escape/ручку-хэндл клавиатуры — проверить, коммитится ли формула и закрывается ли клавиатура. По коду сейчас `DEBUG_KEEP_KEYBOARD_OPEN = true` → ожидаемо клавиатура **не закрывается сама** и поле **не коммитится** по обычному blur. Если на стенде так и есть — это баг/незавершённая правка (стоит сообщить автору), если нет — код на стенде отличается от прочитанного, тоже стоит переуточнить.
17. **TC17.** Ручка-хэндл над клавиатурой (полоска, `aria-label="Закрыть клавиатуру"`) — клик по ней коммитит поле и закрывает клавиатуру.
18. **TC18.** Переключение вкладки браузера / сворачивание приложения при открытой клавиатуре MathLive (`visibilitychange`) → клавиатура скрывается (но поле как таковое не обязано коммититься — проверить фактическое поведение).
