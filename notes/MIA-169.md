## Контекст

Тривиальная задача: добавить в футер сайта ссылки на канал в MAX и Telegram. Задача содержит только два URL, без текста постановки - весь скоуп раскрыт кодом MR !412 (`feat/MIA-169-footer-social-links`, смержен в master, тег `2026.09.15.2`).

По комментарию разработчика: футер общий для всего сайта, поэтому блок соцсетей виден и на лендинге, и в блоге, и на правовых страницах (не только на главной).

## Реализация

Код прочитан целиком (компонент + константы, не только дифф).

- `frontend/constants/legal.ts` - новый экспорт `SOCIAL_LINKS = { max: 'https://max.ru/u/f9LHodD0cOIh995QSQwMo1g0X6Hbi3ANDzZnijYaW9d4TPpOeJnq8A1Y1NA', telegram: 'https://t.me/Mia360tutor' }`, URL совпадают с тем, что дано в тексте задачи Linear дословно.
- `frontend/components/landing/landing-footer.vue` - в колонку `footer__brand` (лого + сигнатура + копирайт) добавлен блок `.footer__socials` с двумя ссылками: Telegram (иконка `/images/social/telegram.svg`, подпись «Telegram») и MAX (иконка `/images/social/max.svg`, подпись «MAX»). Обе ссылки:
  - `target="_blank" rel="noopener noreferrer"` - открываются в новой вкладке, без утечки `window.opener` и без реферера;
  - плоский список `<a>` без кнопок/hover-эффекта, кроме смены цвета текста (`$color-vast` → `$color-fathom` при наведении, тот же паттерн, что у остальных ссылок футера);
  - иконки `22×22`, `loading="lazy"`, `alt=""` (декоративные - подпись текстом рядом уже даёт название соцсети).
- Layout: `.footer__socials` - `flex; flex-wrap: wrap; column-gap: 20px; row-gap: 8px` - две ссылки не переносятся на отдельные строки на обычных ширинах, но перенесутся, если места не хватит (узкий экран).
- Адаптив самого футера не менялся этим MR: `@media (max-width: 800px)` - сетка колонок футера 4→2, `@media (max-width: 500px)` - 2→1 (правила, существовавшие до этой задачи, блок соцсетей встроен в первую колонку и наследует её адаптив без отдельных правил).
- Аналитики на клик по соцсетям в диффе нет (проверено: `frontend/constants/analytics-events.ts`/`api/src/constants/analytics-events.ts` не тронуты, слова `social`/`footer` в них не встречаются) - не пункт для этого раунда.

## Тест-кейсы

Короткий UI-чек-лист (тривиальная задача).

1. Открыть главную страницу, долистать до футера. В левой колонке (лого + сигнатура) под текстом «ИИ-сервис для подготовки...» должны быть две ссылки с иконками - Telegram и MAX, над строкой копирайта «© 2026 ООО «МИА ИНТЕЛЛЕКТ»».
2. Клик по «Telegram» → открывается новая вкладка на `https://t.me/Mia360tutor` (реальный, существующий канал/чат).
3. Клик по «MAX» → открывается новая вкладка на `https://max.ru/u/f9LHodD0cOIh995QSQwMo1g0X6Hbi3ANDzZnijYaW9d4TPpOeJnq8A1Y1NA` (реальное, существующее сообщество).
4. Навести курсор на каждую ссылку - цвет текста должен меняться (hover-состояние), курсор - pointer.
5. Проверить, что обе иконки отрисовались (не битые SVG) на десктопе.
6. Проверить футер не только на главной, но и на любой другой странице с тем же футером (например, блог или страница политики ПДн) - блок соцсетей должен быть виден и там же.
7. Адаптив: сузить окно до мобильной ширины (~375px) - ссылки должны остаться читаемыми, при нехватке места переноситься на новую строку (`flex-wrap: wrap`), без наложения на соседние элементы колонки.
8. Убедиться, что добавление блока не сломало верстку остальных трёх колонок футера («Продукт», «Правовое», «Реквизиты») на десктопе и на брейкпоинтах 800px/500px.
