# Mockups index

Карта соответствия экранов приложения и скриншотов макетов. Агент читает этот файл, чтобы подобрать нужный экран к задаче Linear при написании UI-проверок.

**Как пополнять:** клади PNG экрана в эту папку и добавляй строку в таблицу. Имя файла — по экрану, латиницей (напр. `diagnostic-start.png`). В колонке «Область / фича» — ключевые слова, по которым агент сматчит задачу с экраном.

| Экран | Файл | Область / фича | Заметки |
|-------|------|----------------|---------|
| _пример_ Старт диагностики | diagnostic-start.png | diagnostic, диагностика | первый экран после входа |
| _пример_ Тренажёр: тема | trainer-topic.png | trainer, тренажёр, задачи | экран решения задач |
